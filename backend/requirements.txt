# ----------------------------------------------------------------------
# BAIF Bhasha - unified backend requirements (shared base)
#
# Merges BAIF-main (documents), BhaaratAwaaz-main (audio) and
# BAIF-Video-main (video) into one dependency set. Confirmed-unused deps
# from the original projects are dropped: easyocr, loguru, ffmpeg-python,
# langdetect (source language is now always explicit from the frontend,
# so per-cell language auto-detection is no longer needed).
#
# `parler_tts` is installed from GitHub, which is a build-time requirement
# only (git + network needed once, while building the venv/PyInstaller
# bundle) -- once installed, it freezes into a packaged app like any other
# dependency. Its own setup.py pulls in `descript-audiotools` from git too
# (unpinned) -- do NOT also pin descript-audiotools here yourself: pip
# treats a separately-pinned direct-URL requirement for the same package as
# a distinct, conflicting specifier and refuses to resolve it, even when it
# would land on the identical commit. Let parler_tts's own dependency bring
# it in.
#
# This file deliberately excludes torch/torchaudio: those differ between
# the CPU and GPU builds and live in requirements-cpu.txt / requirements-gpu.txt
# instead, which both pull in this file via `-r requirements.txt`. Install
# one of those two directly -- do not `pip install -r requirements.txt` on
# its own, it has no torch build in it at all. See PACKAGING.md step 2.
# ----------------------------------------------------------------------
